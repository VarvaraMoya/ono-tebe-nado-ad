# Оно тебе надо

Одностраничный сайт аукциона вещей, в которые никто не верил. В проекте использованы семантический HTML, CSS Grid, Flexbox и локальный шрифт Raleway.

Чтобы посмотреть страницу, откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

Репозиторий проекта: https://github.com/VarvaraMoya/ono-tebe-nado-ad
